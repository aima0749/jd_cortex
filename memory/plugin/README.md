# Memory plugin (C# ARC Behavior Control)

Inside ARC: connection light, live "What JD sees" card, clickable example
questions, ONE input box and hold-to-talk button for everything (memory
questions and free-text commands alike — the Python side routes them), a
hand-gesture-control toggle with a plain-language legend, and a guarded
shutdown button. It also grabs JD's camera frames and writes them atomically
to the shared **bridge folder** (`frame.jpg`) for the Python side. The plugin
asks the running Python for that folder's path each time it connects (the
`bridgedir` command), so there is nothing to edit here — the `D:\face_bridge`
value near the top of `MainForm.cs` is only a fallback used before the first
connection.

It talks to the Python brain over TCP `127.0.0.1:5005` with a line protocol:
free text -> `OK: <answer>`, `listen start` / `listen stop` (hold-to-talk),
`gesture on` / `gesture off`, `status`, and `stop`.

## Building

This is a complete Visual Studio project generated by ARC's Create Robot
Skill wizard (so the SDK references match a standard ARC install). Open
`MY_PROJECT_NAME.csproj`, press Build, and the plugin DLL is placed into
ARC's plugin folder automatically. Then in ARC: Project -> Add Skill ->
Beta -> Memory. ARC and the SDK are Windows-only.
